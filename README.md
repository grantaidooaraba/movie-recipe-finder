# Movie Finder
A small, responsive film browsing shelf with useful search, genre filters, title details, and a no-results state.

## Run locally
Requires Node.js 20.19+ or 22.12+. Run `npm install`, `npm run dev`; use `npm run build` for production.

## Features
- Search titles, directors, years, and genres.
- Browse genre filters, open film details, reset the search, and see an intentional empty state.
- Responsive locally curated catalog, requiring no credentials or network service.

## Data and limitations
The included catalog is a sample selection for this assignment, not live availability or personalized recommendations. Film information is stored locally in `src/App.jsx`.
